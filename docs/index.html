NFL Props Stats

Real NFL player and team statistics for PrizePicks-style props analytics

Rule: ZERO fabricated numbers. Every row is downloaded from public nflverse releases or locally aggregated from those rows. If a source fails, the error is recorded — data is never invented.

Features

🔍 Search

Fuzzy player name search with headshots, team logos, jersey numbers, and season/weekly stats from real parquet data.

📊 Weekly Predictions

Model estimates for player props with actuals, ESPN/Vegas comparisons (when loaded), and confidence flags.

🎴 Build My Card

PrizePicks-style entry builder with 2-6 player selections, team browser, randomize, and session persistence.

📖 Guide

Active games tracker, challenge locked cards with live actuals, and model improvement suggestions based on real signals.

Data Sources

All data comes from nflverse public releases via the nflreadpy Python package:

  • Weekly player stats, snap counts, injuries
  • Team schedules, depth charts, player roles
  • Player usage metrics (derived from stats + snaps)
  • Team logos and player photo URLs (ESPN CDN)

Optional external data (user-supplied CSV only): ESPN projections, Vegas lines — never invented.

Running Locally

Setup and refresh data:

cd nfl-props-stats
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/refresh_nfl_stats.py

Start the Flask UI:

./scripts/run_ui.sh

Then open http://127.0.0.1:5056/ in your browser.

Note: The UI runs on your local machine. Default port is 5056; configure via scripts/config.py.
